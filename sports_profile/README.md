# Basketball Coach Brochure

This is a static brochure page built with React.

## Features

- Two-column layout
- Basketball coach profile
- Reusable React components
- CSS styling

## Technologies

- React
- JavaScript
- CSS
- Vite

## How to Run

1. Install dependencies:

```bash
npm install
```

2. Start the project:

```bash
npm run dev
```

3. Open the link shown in the terminal.
